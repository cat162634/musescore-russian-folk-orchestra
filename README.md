# Оркестр русских народных инструментов (ОРНИ) для MuseScore 4

Полный комплект для нотации партитур оркестра русских народных инструментов в **MuseScore Studio 4**:
- **Плагин-конструктор (`Plugins/NarodniyOrkestr/NarodniyOrkestr.qml`)** с выбором состава по пресетам или галочками по каждому инструменту.
- **4 готовых шаблона `.mscz` (`Templates/Народный оркестр/`)** от малого учебного до максимального полного состава на 57 партий (64 нотных стана).

## Состав инструментов (57 партий, академический порядок партитуры)

1. **Деревянные и народные духовые (16)**: Флейта-пикколо, Флейта I–II, Альтовая флейта (in G), Гобой I–II, Английский рожок (in F), Кларнет (in B♭), Фагот, Свирель, Жалейка, Кугиклы, Владимирские рожки (сопрано, альт, тенор, бас).
2. **Баяны и гармоники (5)**: Баян I, II, III (готово-выборные, по 2 стана), Бас-баян, Гармоника / хромка (2 стана).
3. **Ударные симфонические и народные (15)**: Литавры, Ксилофон, Колокольчики, Оркестровые колокола, Малый барабан, Большой барабан, Тарелки, Там-там, Треугольник, Бубен, Бубенцы, Ложки, Трещотка, Деревянная коробочка, Рубель.
4. **Гусли и цитровые (4)**: Гусли звончатые, Гусли клавишные (2 стана), Гусли щипковые (2 стана), Цимбалы (2 стана).
5. **Домры трёхструнные (10)**: Домра пикколо (`+12`), Домра малая I–II, Меццо-сопрано, Альтовая I–II (`-12` в скрипичном ключе), Теноровая (`-12`), Басовая I–II, Контрабасовая (`-12`).
6. **Балалайки (7)**: Пикколо, Прима I–II, Секунда, Альт (`G8vb`), Бас, Контрабас (`-12`).

Для каждого инструмента прописаны русские названия и сокращения, ключи, транспозиция, игровые диапазоны, открытые струны (для домр и балалаек), групповые/парные акколады и тембры воспроизведения.

## Быстрая установка

### Windows
1. Скачайте репозиторий (Code → Download ZIP) и распакуйте.
2. Запустите `Установить_в_MuseScore4.bat`.
3. Перезапустите MuseScore 4.

### macOS / Linux
```bash
chmod +x install_musescore4.sh
./install_musescore4.sh
```

### Где искать после установки
- **Готовые шаблоны**: `Файл → Создать → Выбрать шаблон → Народный оркестр`
- **Плагин-конструктор**: включите один раз в `Плагины → Управление плагинами` («Народный оркестр (ОРНИ)»), затем запускайте через `Плагины → Инструменты для композиции и аранжировки`.
