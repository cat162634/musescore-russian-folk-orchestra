ОРКЕСТР РУССКИХ НАРОДНЫХ ИНСТРУМЕНТОВ (ОРНИ) — ПЛАГИН И ШАБЛОНЫ ДЛЯ MUSESCORE 4
==============================================================================

В архиве два инструмента для работы:
  1) Готовые шаблоны (.mscz) — открываются прямо в «Файл → Создать → Выбрать шаблон».
  2) Плагин-конструктор (NarodniyOrkestr.qml) — позволяет отмечать галочками нужные
     инструменты, задавать название, размер, тональность, число тактов и формат страницы.

БЫСТРАЯ УСТАНОВКА:
  - Windows: распакуйте архив и запустите «Установить_в_MuseScore4.bat».
  - macOS / Linux: запустите «./install_musescore4.sh» в терминале.

РУЧНАЯ УСТАНОВКА (если папка MuseScore4 находится в другом месте):
  1. Папку «Plugins\NarodniyOrkestr» скопируйте в: Документы\MuseScore4\Plugins\
  2. Папку «Templates\Народный оркестр» скопируйте в: Документы\MuseScore4\Templates\
  3. В MuseScore 4 откройте: Плагины → Управление плагинами → включите «Народный оркестр (ОРНИ)».

ГОТОВЫЕ ШАБЛОНЫ В КОМПЛЕКТЕ:
  01-ОРНИ_Полный_состав_(все_инструменты).mscz  — все 57 партий (64 стана), A3
  02-ОРНИ_Академический_большой_состав.mscz     — академический состав (типа орк. Осипова), A3
  03-ОРНИ_Концертный_состав.mscz                — стандартный концертный состав, A3
  04-ОРНИ_Малый_учебный_состав.mscz             — учебный струнно-баянный состав, A4
